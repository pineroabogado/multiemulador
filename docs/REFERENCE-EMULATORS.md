# Emuladores de referencia (local)

La carpeta `EMULADORES/` del disco de desarrollo **no se sube a git** (binarios grandes / licencias mixtas). Solo se documenta aquí la lista canónica usada para contrastar timing y carga.

| # | Emulador | Notas |
|---|----------|--------|
| 1 | Fuse 1.10.1 | Referencia open source; floating bus 14338 |
| 2 | ZEsarUX 13.x | Misma familia de timings; muchas máquinas |
| 3 | SpecEmu 3.4 | Muy preciso en Windows |
| 4 | Retro Virtual Machine 2.x | UI moderna; Z80/sonido cuidadosos |
| 5 | Spectaculator 9.x | FlashLoad / uso casual en Windows |

Sitios: fuse-emulator.sourceforge.net · github.com/chernandezba/zesarux · specemu.zxe.io · retrovirtualmachine.org · spectaculator.com

Ver también `docs/TIMING-ARKANOID.md`.
